# Windows IT Support & System Administration Labs

## Overview

This repository documents my hands-on training in Windows troubleshooting, networking, and system administration.

I hold a B.S. in Cybersecurity and Information Assurance, along with CompTIA Security+, Network+, and Project+ certifications.

My objective is to develop practical IT support skills through simulated incidents, systematic troubleshooting, and documented resolutions, while progressively building toward Windows system administration.

## Lab Environment

- **Virtualization:** Oracle VirtualBox
- **Operating System:** Windows 11
- **Networking:** VirtualBox NAT
- **Tools:** PowerShell, Windows networking utilities, and built-in diagnostic tools

## Lab Projects

### 01 — Network Troubleshooting

**DNS Resolution Failure — Simulated Incident**

Diagnosed a DNS resolution failure caused by an intentionally misconfigured DNS server.

Topics covered:
- IPv4 addressing, DHCP, and DNS configuration
- Comparing configured DNS resolution against direct DNS queries
- Distinguishing network connectivity from name resolution
- PowerShell-based configuration and recovery
- Post-remediation verification
